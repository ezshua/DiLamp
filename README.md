# DiLamp

Умная лампа с адресуемой многоцветной подсветкой WS2812. Два вложенных кольца светодиодов (12 + 8 = 20 шт.) на верхней грани цилиндрического корпуса, накрытые рассеивателем.

Управление — тремя кнопками на корпусе. Питание — от USB или от встроенного аккумулятора. Диагностика и консоль — через последовательный порт 115200 бод.

**Аппаратные решения и их обоснование — [docs/PLAN.md](docs/PLAN.md).**

## Требования

- VS Code с расширением **PlatformIO IDE**
- PlatformIO Core 6.x (проверено на 6.2.0)
- Плата **Arduino Nano** на ATmega328P, 16 МГц
- Сеть при первой сборке — скачиваются toolchain'ы и библиотеки

## Сборка и прошивка

### В VS Code

1. Открыть папку проекта в VS Code.
2. Выбрать окружение в статус-баре (по умолчанию `nano`).
3. Панель **PROJECT TASKS** → **Build** / **Upload** / **Monitor**.
4. **TESTING** → **Test All** для нативных тестов.

### В терминале

```bash
pio run -e nano                 # сборка
pio run -e nano -t upload       # прошивка
pio device monitor -b 115200   # монитор
pio test -e native              # нативные тесты, без железа
pio run -e nano -t size         # отчёт по памяти
```

При первой сборке PlatformIO скачает платформу `atmelavr` и библиотеку Adafruit_NeoPixel — нужна сеть.

## Управление кнопками

| Действие | NEXT | PREV | PAUSE |
|---|---|---|---|
| Короткое нажатие | следующий эффект | предыдущий эффект | пауза / снятие |
| Удержание (≥800 мс) | яркость + | яркость − | — |
| Очень долгое (≥1500 мс) | — | — | мягкое вкл./выкл. |

## Последовательная консоль

115200 бод, перевод строки. Одна и та же строка работает и как человеком, так и для автоматизации.

| Команда | Аргументы | Действие |
|---|---|---|
| `help` | — | Список команд |
| `status` | — | Эффект, яркость, напряжение, uptime, потери лога |
| `battery` | — | Напряжение и расчётный ток |
| `log` | `error` \| `warn` \| `info` \| `debug` | Уровень подробности |
| `effect` | `0..5` \| `next` \| `prev` \| `<имя>` | Выбор эффекта |
| `brightness` | `0..180` | Яркость |
| `save` / `load` / `reset` | — | Настройки в EEPROM |
| `reboot` | — | Перезагрузка через WDT |

## Эффекты

| Индекс | Имя | Описание |
|---|---|---|
| 0 | `radial` | Оттенок плавно идёт по радиусу от центра к краю, медленное вращение |
| 1 | `solid` | Один цвет на оба кольца |
| 2 | `rainbow` | Радуга по кольцу |
| 3 | `breathe` | Общая яркость синусом |
| 4 | `wave` | Яркий импульс бежит по кольцу |
| 5 | `pulse` | Медленный импульс, 1 в секунду |

## Этап 2 — Ядро

- [ ] **6. `Color`.** HSV→RGB таблицей 768 Б в PROGMEM, `lerpRgb`.
  - *Приёмка:* тест на граничных оттенках (0, 64, 128, 192, 255) и на насыщенности 0 и 255.

- [ ] **7. `LedBus`.** Обёртка над NeoPixel с dirty-флагом.
  - *Приёмка:* `show()` вызывается только при изменении кадра; флаг сбрасывается после вывода.

- [ ] **8. `RingLayout`.** Маппинг «кольцо + индекс» → индекс ленты, направление и смещение настраиваемы.
  - *Приёмка:* тест на всех 20 позициях в обе стороны; обратный порядок даёт корректный маппинг.

- [ ] **9. `SettingsStore`.** Версионированная структура + CRC поверх avr-libc EEPROM.
  - *Приёмка:* битая запись, неизвестная версия и первый запуск дают безопасные значения по умолчанию.

- [ ] **10. `Logger`.** Уровни, кольцевой буфер 128 Б, неблокирующий сброс 32 Б за итерацию.
  - *Приёмка:* переполнение теряет старые записи и считает их; при flush кадры не пропускаются.

- [ ] **11. `CommandConsole`.** Побайтовый парсер, таблица команд, ответы `OK` / `ERR`.
  - *Приёмка:* `help`, `status`, `log`, `effect`, `brightness`, `save`, `load`, `reset`, `reboot` отвечают; битый аргумент даёт `ERR` и не меняет состояние.

- [ ] **12. `Controls` + `Buttons3` + `EncoderKnob`.** `Buttons3` включён, `EncoderKnob` — задел, отключён.
  - *Приёмка:* дебаунс 40 мс отсекает дребезг; удержание не вызывает цикл переключения; оба класса собираются.

- [ ] **13. `Effects` — 6 эффектов в одном файле `src/effects.cpp`.** `RadialGradient`, `SolidColor`, `RainbowCycle`, `Breathing`, `RunWave`, `ClockPulse`.
  - *Приёмка:* каждый эффект читается отдельно, `main.cpp` остаётся чистым оркестратором; переключение эффекта — один вызов.

- [ ] **14. `BatteryMonitor`.** Делитель на A0, нормализация по `DILAMP_ADC_BITS`, порог 3,3 В.
  - *Приёмка:* 4,2 В читается как 4,2 В и на 10-битной, и на 12-битной плате; ниже 3,3 В — угасание и лог.

- [ ] **15. `main.cpp` как конечный автомат.** Ввод → логи → эффект → `show()` при изменениях → `SettingsStore`.
  - *Приёмка:* кнопки, пауза, плавное выключение работают; ни одного блокирующего вызова в цикле.

- [ ] **16. Плавный старт и кроссфейд 300 мс.**
  - *Приёмка:* при включении лампа нарастает за ~600 мс без белой вспышки; переключение эффекта идёт кроссфейдом; нажатие во время кроссфейда не даёт скачка.

## Ручные приёмочные тесты

Заполняется владельцем на реальном железе. Подробные ожидания — план §9.

- [ ] Включение без нажатий → плавное нарастание, без белой вспышки
- [ ] Короткое NEXT / PREV → листаются эффекты с кроссфейдом 300 мс
- [ ] Удержание NEXT / PREV → ступенчатая яркость в пределах 0…180
- [ ] Короткое PAUSE → эффект замирает, повторное — оживает
- [ ] Длинное PAUSE → плавное угасание и разгорание
- [ ] Отсоединение USB → переход на аккумулятор без перезагрузки логики
- [ ] Тумблер → лампа гаснет только в режиме аккумулятора
- [ ] Разряд ниже 3,3 В → плавное угасание и запись в Serial
- [ ] `pio run -e nano` и `pio run -e lgt` → обе платы собираются
- [ ] 2 мин белый 100 % → нет просадки 5 В, MT3608 не уходит в защиту
- [ ] `help` и `status` в мониторе → ответы, лампа не замирает
- [ ] `log debug` при активном эффекте → кадры не пропускаются, потерь нет
- [ ] `brightness 200` (выше лимита) → `ERR`, яркость остаётся в пределах 0…180
